*^^* Oking's 맥체인 성경읽기표 ^^"

· 날짜 숫자 클릭 시 극동방송 맥체인 날짜별 성경읽기 영상이 새 탭으로 열림
· 성경 본문 클릭 시 대한성서공회 새 탭으로 열림
· 유튜브 아이콘(▶) 클릭 시 공동체성경읽기 유튜브 새 탭으로 열림
· 여러 장 범위는 첫 장 기준으로 연결됨
· 각 본문 클릭 시 새 탭으로 성경 열림 + “읽음(회색/취소선)” 상태가 동일 브라우저에 저장됨
· 다른 브라우저 또는 다른 기기에서 열면 읽음 표시는 새로 시작
